# Файлы для разбора нового детектора

Переданы по запросу команды 13 ноября 2026 года. Результаты и настройки: [отчёт](../../reports/redetect_strong.md).

- `pred_day_20261025.csv`: модель обучалась на 25 октября, предсказания сделаны на кадрах **26 октября**.
- `pred_day_20261026.csv`: модель обучалась на 26 октября, предсказания сделаны на кадрах **25 октября**.
- `oof_features.csv`: 198 исходных оцениваемых боксов train с официальными метками `error` и признаками согласия с моделью, которая не видела их день при обучении. `x1,y1,x2,y2` здесь относятся к исходному детектору, а не к новому.

В сырых файлах каждая строка — бокс нового детектора: `frame_id`, класс, уверенность и координаты в пикселях исходного изображения. Они включают контекстные кадры и вспомогательные классы. Порог сохранения уверенности — 0.01; при расчёте признаков согласия использован порог 0.05. Для сопоставления используйте `frame_id` и класс, а не номер строки. Отсутствие строки может означать отсутствие детекции.

`iou_same` — максимальное IoU с новым боксом того же класса; `conf_at_best` — уверенность этого бокса; `match_conf` — максимальная уверенность среди боксов того же класса с IoU >=0.6. Это независимый поиск пары для каждого исходного бокса, а не взаимно однозначное сопоставление.

`pred_all.csv` пока отсутствует: итоговая модель на обоих днях ещё обучается. Позже этот файл будет содержать предсказания на **test**, без ручных меток правильности. В этой передаче нет весов, изображений или отправки на Kaggle.
