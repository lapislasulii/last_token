# Синтетические боксы: результат трёх запусков

**Итог: идея дала локальный прирост среднего AP, но строгий критерий задания прошёл только один из трёх случайных наборов. Не считаем улучшение устойчиво подтверждённым и не заменяем текущего лидера Kaggle. Отправок не было.**

## Что сделали простыми словами

Взяли ручные прямоугольники на train, сдвигали, растягивали и обрезали их. Добавили примеры на посторонних предметах. CLIP смотрел на фрагмент с красной рамкой, а небольшая модель училась отличать правильные границы от неправильных. Проверяли только на настоящих детекциях другого дня.

Использованы 240 ручных боксов четырёх оцениваемых классов, а не все 1032 строки исходной таблицы. Ошибка искусственного примера считается по максимальному IoU со ВСЕМИ ручными боксами нужного класса этого кадра. Сдвиг к другому человеку не объявляется ошибкой автоматически. Кандидат на ложное срабатывание пропускается, если совпадает с нужным классом при IoU >=0.6.

Каждый искусственный кандидат рассматривается отдельно. Это цель качества геометрии/класса, а не полная официальная задача взаимно однозначного сопоставления нескольких детекций; дубли такой генератор специально не учит.

## Объём и настройки

Один рецепт генератора, seed 42, 43 и 44. Соответственно 9377/9378/9379 сгенерированных примеров. После балансировки: 6954/7028/7036 примеров. Вместо подбора долей искажений убирали избыток одного ответа отдельно для каждого класса и дня до 50/50. Порог и ответы не меняли; доли балансировали без использования качества на отложенном дне. Это явное отличие от первоначального задания.

Картинки происходят всего из 38 кадров. Посмотрены по 20 случайных примеров каждого класса первого seed. Для людей есть обрезка снизу и расширение, для маленьких объектов видна низкая исходная детализация. Рамка всегда красная независимо от метки. Первые листы показывают IoU с округлением до двух знаков: 0.60 может оказаться по любую сторону порога; код метку считает по полному значению, новая версия подписей выводит четыре знака.

Замороженный [CLIP ViT-L/14](https://huggingface.co/openai/clip-vit-large-patch14), revision 32bd64288804d66eefd0ccbe215aa642df71cc41. Crop1.5x/pad224 и рамка совпадают с текущей CLIP-схемой. GPU batch16 вместо предложенного64. StandardScaler → PCA64 → логистическая регрессия C=1, плюс категория объекта. Нет исходной уверенности детектора среди входов синтетической модели. Все обучаемые настройки fit только на синтетике другого дня.

Итоговая смесь: отдельно в каждом дне ранжируем визуальный score и 1-confidence, переводим места в доли очереди и усредняем 50/50. Вес не подбирали. PCA randomized с фиксированным random_state42. Настройки не менялись между seed.

## AUC самостоятельного визуального score

AUC здесь измеряет, насколько часто ошибка получает более высокий score, чем правильный бокс. Сравнение — с 1-confidence, не confidence. Ниже оба OOF-дня вместе, как в исходном задании; подробные показатели по дням лежат локально в auc.csv. Pooled AUC зависит также от сопоставимости шкал двух обученных моделей.

| Класс | baseline AUC | seed42 | seed43 | seed44 |
|---|---:|---:|---:|---:|
| cup | 0.793651 | 0.769841 | 0.793651 | 0.750000 |
| nude_hands | 0.708440 | 0.657289 | 0.700767 | 0.671355 |
| person | 0.743690 | 0.710938 | 0.706731 | 0.746394 |
| tray | 0.737500 | 0.500000 | 0.425000 | 0.325000 |

Сам по себе визуальный score не превосходит baseline по совокупной AUC классов во всех запусках; полезен в сочетании с исходной уверенностью. На seed42 смесь улучшила AP людей и рук обоих дней относительно CLIP, но ухудшила подносы. Для подносов мало настоящих примеров, на первом дне всего три.

## Что сохранили и как повторить

Код и тесты в ветке codex/synthetic-boxes. Исходный локально изменённый README не включён. Индивидуальные примеры, картинки, признаки и OOF остаются в игнорируемых outputs/ и oof/.

```powershell
python -m pip install -r model_releases/requirements-visual.txt
python tools/train_marked_context.py --encoder clip --batch-size 4
python tools/train_synthetic_boxes.py --seed 42 --batch-size 16
python tools/train_synthetic_boxes.py --seed 43 --batch-size 16
python tools/train_synthetic_boxes.py --seed 44 --batch-size 16
python -m unittest discover -s tests -v
```

Первый CLIP-запуск нужен только если ещё нет кэша настоящих train/test-боксов. Его модель и revision проверяются. Для каждого seed сохранены таблицы и метрики. Скрипт обучает финальную модель и создаёт test CSV только при выполнении исходного критерия успеха. В этом эксперименте такой файл создан только для seed43.

Сохранён артефакт model_releases/synthetic_seed43.joblib для воспроизведения, НЕ как новый подтверждённый лидер. Восстановление:

```powershell
python tools/predict_synthetic_boxes.py model_releases/synthetic_seed43.joblib
```

Результат: submissions/synthetic_rankblend_seed43.csv, 362 строки. Восстановленная модель воспроизводит исходный CSV; ID и диапазон проверены. Все три OOF-файла смеси пересчитаны общим evaluator. Три новых unit-теста проверяют совпадение с другим объектом, отсутствие нужного класса, частичный бокс и обрезку crop у границы; полный набор из13 тестов прошёл.
