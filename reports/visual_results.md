# Визуальная поправка к confidence — 12 ноября 2026

Лучший текущий Public: **0.65944**, baseline: **0.64114** (+0.01830 AP). Это результат visual_residual_context_l1. Private неизвестен.

## Идея и ограничения

Готовый замороженный [facebook/dinov2-small](https://huggingface.co/facebook/dinov2-small) извлекает 384 признака изображения. Новые боксы не строятся: используются только существующие детекции. Веса публичные, Apache-2.0, revision `ed25f3a31f01632728cabb09d1542f84ab7b0056`. [Источник весов](https://huggingface.co/facebook/dinov2-small/tree/ed25f3a31f01632728cabb09d1542f84ab7b0056).

Две области: сам бокс и бокс, расширенный в 1.5 раза относительно центра. Область обрезается по границам изображения, масштабируется с сохранением пропорций и дополняется до 224×224 (RGB 124/116/104), затем ImageNet-нормализация. Используется CLS-токен. Координаты пересчитываются по фактическим размерам изображения.

Обычная логистическая регрессия на 384/768 признаках плюс confidence проиграла baseline. Более устойчивый вариант оставляет исходный риск `p0 = 1-confidence` и обучает поправку: `score = sigmoid(logit(p0) + PCA_features @ w)`. p0 ограничивается диапазоном [1e-5,1-1e-5]. StandardScaler и PCA до 16 компонент с whitening обучаются только на обучающем дне. Минимизируется средняя binary cross-entropy плюс `lambda * ||w||² / 2`; свободного intercept нет. Lambda=10 означает меньшую поправку, чем lambda=1.

Гибрид дополнительно использует стандартизованные геометрические признаки, one-hot класс и, в отдельном варианте, четыре CORE временных признака. Эти признаки обучаются совместно с визуальной поправкой. На Public гибрид уступил чистому визуальному контексту.

198 обучающих детекций, 362 тестовые. Два UTC-day fold, без table; никакой ручной разметки теста, ручных боксов как входа или machine pool. Извлечение признаков test — только замороженный encoder. Финальные головы обучены на всех 198 строках, их оценка на этих же строках не является валидацией.

Перебор: 6 обычных голов и их смеси 50/50 (12 кандидатов), затем 6 residual-кандидатов, затем 4 гибрида. Всего 22 визуальных варианта на тех же двух днях. Отбор не является независимым подтверждением; Public также использовался для сравнения. Небольшой прирост нельзя считать доказанным на новых днях.

## Воспроизведение

Из корня репозитория; датасет в `data/rascar-hack-case-1/`. Python 3.13, проверено на RTX 5070 Ti Laptop GPU, PyTorch 2.11.0+cu128. На CPU код также допускает запуск, но скорость не проверялась.

```powershell
python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r model_releases/requirements-visual.txt
python tools/train_visual.py
python tools/train_visual_residual.py --predict model_releases/visual_residual_context_l1.joblib
```

Первый запуск скачивает публичный encoder в игнорируемую weights/hf, извлекает признаки и обучает обычные визуальные головы. Кэш содержит проверки ID и SHA-256 входов. Для воспроизведения обучения residual и hybrid:

```powershell
python tools/train_visual_residual.py
python tools/train_visual_hybrid.py
python tools/evaluate_predictions.py score oof/visual_residual_context_l1.csv --mode oof --name visual_residual_context_l1
python -m unittest discover -s tests -v
```

Выходы: submissions/, oof/, models/, outputs/visual_features/; они исключены из Git. Скрипты обучения не отправляют ничего на Kaggle. Сохранённая residual-голова требует кэш того же encoder и preprocessing. Публикуются две маленькие головы, а не полные веса DINOv2. Метаданные и SHA-256 находятся в model_releases/visual_metadata.json.
