# Ансамбль детекторов: локальная проверка и следующий эксперимент

## Вывод

**Ансамбль трёх YOLO11l не прошёл заранее заданный критерий: с вето Вовы он уступил исходной модели на обоих проверочных днях.** Текущий проверенный вариант остаётся прежним — Public AP 0.82471. У ансамбля результата Kaggle пока нет.

После обсуждения пользователь отдельно разрешил продолжить эксперимент: обучить два итоговых участника на обоих днях, несмотря на отрицательную локальную проверку. Это осознанное исключение из условия остановки в задании, а не изменение вывода о локальном качестве.

## Что проверили

Обучены четыре дополнительные дневные модели: seed 1 и 2, каждый на 25 и 26 октября отдельно. Предсказания всегда сделаны на противоположном дне. Исходный участник `base` — seed 0, его не переобучали.

Рецепт одинаковый: публичные веса YOLO11l, 250 эпох, размер 1280, batch 4, 12 классов. Использованы последние веса, без выбора эпохи по отложенному дню. Все четыре запуска завершились.

Каждый участник голосует, есть ли у исходного бокса пара того же класса с IoU >=0.6. D — доля участников, которые не нашли пару. Координаты боксов не усредняются. Ответ детектора: `(1 − confidence + D) / 2`; после добавления бинарного вето V: `(1 − confidence + D + 2V) / 4`.

## Результаты

AP больше — лучше. Среднее — среднее двух дневных значений, не доля правильных ответов.

| Вариант | 25 октября | 26 октября | Среднее |
|---|---:|---:|---:|
| Baseline | 0.8607 | 0.7648 | 0.8128 |
| base без вето | 0.9147 | 0.8455 | 0.8801 |
| s1 без вето | 0.9097 | 0.8367 | 0.8732 |
| s2 без вето | 0.8967 | 0.7806 | 0.8386 |
| Ансамбль без вето | 0.9065 | 0.8279 | 0.8672 |
| **base + вето — текущий вариант** | **0.9076** | **0.8915** | **0.8996** |
| s1 + вето | 0.8982 | 0.8841 | 0.8912 |
| s2 + вето | 0.8955 | 0.8696 | 0.8825 |
| **Ансамбль base+s1+s2 + вето** | **0.9005** | **0.8818** | **0.8912** |

Оба новых seed оказались слабее исходного. Усреднение не компенсировало это: средний AP снизился примерно на 0.0084. Заранее требовались рост среднего и отсутствие ухудшения на каждом дне; оба требования не выполнены.

Участники расходятся на **48 из 198 боксов (24.2%)**. Распределение голосов:

- все подтверждают бокс, D=0: 58;
- один не подтверждает, D=1/3: 26;
- два не подтверждают, D=2/3: 22;
- ни один не подтверждает, D=1: 92.

Следовательно, чувствительность к случайности обучения действительно есть. Но наличие разных ответов само по себе не делает ансамбль лучше. Эти результаты также не доказывают, что ансамбль исправляет систематические ошибки границ людей.

## Почему всё же готовим test

Проверка охватывает всего два дня. Итоговые модели учатся на 84 кадрах вместо 42, а Public отличается составом примеров, поэтому локальный порядок вариантов не обязательно сохранится. Мы не знаем, поможет ли это ансамблю; отдельная отправка может проверить гипотезу на Public, но не докажет надёжность на Private.

По явному запросу пользователя запущены `all_s1` и `all_s2` последовательно на одной GPU. Ориентир — 67–70 минут обучения плюс предсказания. Состав фиксирован: **base+s1+s2**, без отбора удачных участников по результату. Базовые веса сохраняются.

Очередь подготовит `submissions/redetect_strong_ens-base-s1-s2_veto_veto.csv`. На момент этой публикации обучение только запущено, файл ещё не объявляется готовым. Автоматической отправки на Kaggle в очереди нет. Текущее решение с Public 0.82471 не заменяем по одному факту запуска нового эксперимента.

## Воспроизведение локальной оценки

```sh
python tools/redetect.py eval --tag strong --members base s1 s2
python tools/blend_veto.py train oof/redetect_strong_ens-base-s1-s2_veto.csv
```

Локальные журналы: `outputs/redetect_strong/eval_ens-base-s1-s2.log` и `blend_ens-base-s1-s2.log`. Предсказания: `pred_day_20261025_s1.csv`, `pred_day_20261026_s1.csv`, `pred_day_20261025_s2.csv`, `pred_day_20261026_s2.csv`; признаки ансамбля — `oof_features_ens-base-s1-s2.csv` в той же папке. В этом коммите публикуется вывод, без весов и изображений.
