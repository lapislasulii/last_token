# Self-training: результаты и текущий эксперимент

Обновлено 14 ноября 2026, после запуска итоговой модели около 01:01 МСК.

**Сам ученик не улучшил исходную модель. Но добавление ученика к нашему лучшему отправленному ансамблю улучшает оба локальных дня.** Поэтому по отдельному разрешению пользователя обучается итоговый ученик, затем запланирована одна отправка ансамбля из четырёх моделей с вето. На момент публикации новый результат Kaggle ещё неизвестен. Текущий лучший Public — **0.89753**, без self-training.

## Идея простыми словами

Наш детектор-учитель рисует боксы на дополнительных кадрах machine pool. Новый детектор-ученик обучается на этих приблизительных метках вместе с настоящей ручной разметкой. Ученик начинает с публичных COCO-весов YOLO11l, а не с checkpoint учителя. Дополнительные данные могут дать разнообразие, но ошибки учителя тоже могут закрепиться.

Учитель каждого дневного эксперимента обучен только на своём дне и размечает только пул этого дня. Ученик проверяется на противоположном дне. Из пула явно исключены frame_id train/test и их контекстных кадров. Test не размечали и для обучения не использовали.

## Что изменили относительно задания Клода

Первичный просмотр выявил полностью пропущенного человека, которого старый фильтр не отсеивал. Поэтому перед обучением усилили правила:

- исключаем кадр при любом сомнительном боксе person, nude_hands, cup или tray с уверенностью от 0.25 до 0.5;
- если исходный детектор видит person с уверенностью >=0.5, учитель должен подтвердить его боксом person с уверенностью >=0.5 и IoU >=0.3; иначе кадр исключается;
- сохраняем причины отсева, пороги и количества меток по классам;
- отдельные наборы создаются с `--student-tag`; существующие не удаляются и не перезаписываются.

IoU 0.3 здесь — фильтр согласия для отбора, а не официальный порог правильности 0.6. Полнота псевдоразметки не гарантируется: оба детектора могут пропустить объект. Просмотрены 12 кадров до усиления и 16 прошедших строгий фильтр; остались сомнения по геометрии людей и мелким объектам. Подробности — [аудит псевдоразметки](self_training_audit.md).

YOLO11l, 12 классов, 1280, batch 4, 40 эпох; эпоху по отложенному дню не выбирали. Рецепт после просмотра результатов не менялся.

## Результаты на отложенных днях

Везде ниже добавлено вето экспертов. Больше AP — лучше, среднее — по двум дням.

| Решение | 25 октября | 26 октября | Среднее |
|---|---:|---:|---:|
| Исходный base | 0.9076 | 0.8915 | 0.8996 |
| Ученик st_strict | 0.9057 | 0.8849 | 0.8953 |
| base + ученик | 0.9138 | 0.8878 | 0.9008 |
| Текущий ансамбль base+s1+s2 | 0.9005 | 0.8818 | 0.8912 |
| **base+s1+s2 + ученик** | **0.9108** | **0.8837** | **0.8973** |

Заранее заданный критерий задания (среднее >=0.905 и допустимое снижение каждого дня не более 0.005 от base) **не пройден**. Отрицательный вывод не отменяем.

Дополнительное сравнение с текущим лучшим Public-ансамблем выполнено уже после основной оценки: добавление ученика улучшает оба дня, примерно на 0.0103 и 0.0019. Это исследовательский результат после просмотра метрик, не новая независимая проверка. Он стал основанием для отдельно согласованного Public-эксперимента, а не доказательством будущего улучшения. Исходная модель и ученик расходятся на 38/198 боксов, четыре участника — на 66/198.

## Что запущено сейчас

Итоговый ученик `all_st_strict` обучается на `student_all_strict800` ровно 40 эпох. Затем очередь рассчитает его боксы test, соберёт **base+s1+s2+st_strict** и добавит вето. Формула фиксирована: `(1 − confidence + D + 2V) / 4`, D — доля четырёх детекторов без совпадения IoU >=0.6, V — бинарное вето экспертов.

Ожидаемый файл: `submissions/redetect_strong_ens-base-s1-s2-st_strict_veto_veto.csv`. После проверки 362 уникальных ID, диапазона, конечности оценок и совпадения с формулой очередь выполняет **одну разрешённую отправку**. При ошибке останавливается; повторные отправки автоматически не выполняются. Наличие этого раздела не означает, что файл уже готов или Kaggle посчитал результат.

Лучший ансамбль с Public 0.89753 сохранён отдельно в `outputs/frozen/ensemble_public_0_89753`. Его веса не изменяются.

## Воспроизведение

Окружение как в [отчёте сильного детектора](redetect_strong.md): Ultralytics 8.3.40, NumPy 2.2.6, torch 2.11.0+cu128. Для доверенных checkpoint используется `TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1`.

```sh
python tools/redetect.py pseudo --tag strong --extra-classes --teacher base --student-tag _strict800 --pool-frames 800 --device 0 --predict-batch 4
python tools/redetect.py train --tag strong --student --student-tag _strict800 --member st_strict --seed 0 --weights weights/yolo11l.pt --epochs 40 --batch 4 --device 0
python tools/redetect.py predict --tag strong --member st_strict --device 0
python tools/redetect.py eval --tag strong --members st_strict
python tools/blend_veto.py train oof/redetect_strong_st_strict_veto.csv
python tools/redetect.py eval --tag strong --members base s1 s2 st_strict
```

Для итогового ученика в pseudo/train/predict добавляется `--sets all`. Повторный pseudo с существующим набором намеренно запрещён. Не перезапускать train под существующим именем без необходимости.

```sh
python tools/redetect.py submit --tag strong --members base s1 s2 st_strict
python tools/blend_veto.py test submissions/redetect_strong_ens-base-s1-s2-st_strict_veto.csv
```

Проверки: 18 тестов прошли; дневные обучения и оценка завершились без ошибок. Веса, картинки и псевдометки этим отчётом в Git не публикуются.
