# last_token

Репозиторий команды для работы над хакатоном по компьютерному зрению на данных из кафе.

## Текущее состояние

Сейчас в репозитории собраны начальные материалы. Код решения, зависимости и инструкции по запуску будут добавлены по мере разработки.

## Структура

- `context/transcribation.txt` — автоматическая транскрипция открытия хакатона: организационная информация и описание кейсов. В тексте возможны ошибки распознавания; условия задач нужно сверять с официальными материалами соревнования.
- `context/kaggle_case1.md` — условие кейса 1 с Kaggle ([rascar-hack-case-1](https://www.kaggle.com/competitions/rascar-hack-case-1)): описание задачи, правило ошибки, метрика, формат сабмита, файлы датасета.
- `tools/inspect_data.py` — разбор данных кейса 1: размеры, баланс `error`, бейзлайн `1 − confidence` по дням, классы, типы ошибок, временная устойчивость, контактные листы.
- `reports/data_overview.md` — сгенерированный отчёт по данным (только агрегаты, без самих данных).
- `.gitignore` — правила исключения данных, весов моделей, результатов экспериментов, секретов и локальных файлов окружения.

## Работа с данными

Данные кейсодержателя и исходные записи хранятся локально. Для датасетов предусмотрены каталоги `data/` и `datasets/`, для весов — `weights/` и `checkpoints/`, для сабмитов — `submissions/`. Эти каталоги исключены из Git.

Токены и другие секреты также не должны попадать в репозиторий. Перед коммитом проверяйте список добавленных файлов через `git diff --cached --stat`.

## Кейс 1: аудит детектора

Для каждой детекции на тестовых кадрах нужно выдать `score` ∈ [0, 1] — вероятность, что детекция ошибочная. Метрика — Average Precision (`sklearn`). Детекция ошибочна, если не сопоставилась с ручным боксом того же класса при IoU ≥ 0.6. Сабмиты до 14.11.2026, 23:59 МСК.

Валидация — по UTC-дням train (25.10 ↔ 26.10), класс `table` исключается. Бейзлайн `1 − confidence`: AP ≈ 0.86 / 0.77 по дням.

### Разбор данных

1. Скачать данные соревнования (вкладка Data или `kaggle competitions download -c rascar-hack-case-1`) и распаковать в `data/rascar-hack-case-1/`.
2. Запустить:

```bash
python3 tools/inspect_data.py
```

Нужны `pandas`, `numpy`, `pillow`, `scikit-learn`. Отчёт пишется в `reports/data_overview.md`, контактные листы с боксами — в `reports/*.jpg` (в Git не попадают: на них кадры кейсодержателя).
