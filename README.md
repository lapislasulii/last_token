# last_token

Репозиторий команды для работы над хакатоном по компьютерному зрению на данных из кафе.

## Текущее состояние

Сейчас в репозитории собраны начальные материалы. Код решения, зависимости и инструкции по запуску будут добавлены по мере разработки.

## Структура

- `context/transcribation.txt` — автоматическая транскрипция открытия хакатона: организационная информация и описание кейсов. В тексте возможны ошибки распознавания; условия задач нужно сверять с официальными материалами соревнования.
- `.gitignore` — правила исключения данных, весов моделей, результатов экспериментов, секретов и локальных файлов окружения.

## Работа с данными

Данные кейсодержателя и исходные записи хранятся локально. Для датасетов предусмотрены каталоги `data/` и `datasets/`, для весов — `weights/` и `checkpoints/`, для сабмитов — `submissions/`. Эти каталоги исключены из Git.

Токены и другие секреты также не должны попадать в репозиторий. Перед коммитом проверяйте список добавленных файлов через `git diff --cached --stat`.
