# Задание: self-training сильного детектора на machine pool (нужна видеокарта)

Исполнитель: Семён (RTX 5070 Ti). Ветка: `feat/self-training` (от `codex/redetect-strong`, код уже там).
Ориентир по времени: ~2–2.5 часа на проверку по дням, ещё ~1–1.5 часа на финальную модель, если проверка пройдёт.

## Зачем

Сильный детектор учится всего на 42–84 размеченных кадрах, и результат сильно зависит от случайности обучения:
три seed расходятся на 24% боксов, а ансамбль из них оказался хуже исходного. Это признак нехватки данных,
а не нехватки модели. Machine pool — 5388 кадров тех же дней с той же камеры, но без ручной разметки.

Self-training: обученный детектор («учитель») размечает кадры пула, и новый детектор («ученик») учится на ручных
кадрах + псевдоразметке. Ученик видит тысячи сцен с людьми за столами, а рисует их по конвенции разметчиков,
которую передаёт учитель (проверено глазами на пробном кадре: учитель обводит сидящего вместе с ногами под столом).

## Честность по дням (уже зашито в код)

- Учитель `day_20261025` обучен только на ручных боксах 25.10 и размечает **только пул за 25.10**. Ученик этого fold
  учится на ручных кадрах 25.10 + пуле 25.10 и проверяется на 26.10. 26.10 нигде не участвует. Для второго fold наоборот.
- Учитель `all` (оба дня) размечает пул за оба дня — только для финальной модели на test.
- Кадры train и их контекст в пул не входят (пересечение ноль, проверено). Правила прямо требуют держать день валидации вне обучения.

## Как устроена псевдоразметка (`pseudo`)

- Из пула нужного дня берётся `--pool-frames` кадров: 80% — где исходный детектор видит человека, 20% — любые.
- Учитель прогоняется по ним; в метки идут боксы с уверенностью ≥ 0.5 (`--pseudo-conf`).
- Кадр с неуверенным `person` (0.25–0.5) пропускается целиком: неизвестно, человек это или фон.
  Неуверенные мелкие классы просто не попадают в метки.
- Ручные кадры повторяются `--real-repeat` = 5 раз, чтобы псевдометки их не задавили.
- Картинки пула 640×360; метки нормированные, YOLO сам приводит размер к `--imgsz`.
- Набор ученика — `outputs/redetect_strong/yolo/student_<набор>`, сырые боксы учителя — `pseudo_<набор>_base.csv`.

## Шаги

Все команды из корня репо. Учитель — уже обученный `base` (YOLO11l, 250 эпох, 12 классов), его не трогаем.

### 1. Проверка по дням

```bash
python tools/redetect.py pseudo  --tag strong --extra-classes --teacher base --pool-frames 800 --device 0 --predict-batch 8
python tools/redetect.py train   --tag strong --extra-classes --student --member st --weights weights/yolo11l.pt --epochs 40 --batch 4 --device 0
python tools/redetect.py predict --tag strong --member st --device 0
python tools/redetect.py eval    --tag strong --members st
python tools/blend_veto.py train oof/redetect_strong_st_veto.csv
python tools/redetect.py eval    --tag strong --members base st
```

Почему 800 кадров и 40 эпох: набор ученика ~1000 картинок (210 ручных с повтором + ~800 пула) против 42 у базового.
40 эпох по ~1000 картинок — примерно столько же шагов, сколько 250 эпох по 84, то есть ~1 час на fold по замерам ансамбля.
Число эпох выбрано заранее; по отложенному дню его не подбирать.

Первым делом посмотреть 10–15 кадров `student_day_*/images` с метками (или `pseudo_*_base.csv` в просмотрщике):
обводит ли учитель людей целиком, нет ли массовых ложных `person` на куртках и мишках.

### 2. Критерий (зафиксирован до запуска)

Сравниваем строку `input + veto` из `blend_veto.py` с текущим лучшим вариантом **base + вето: 0.9076 / 0.8915, среднее 0.8996**.

- **Успех:** среднее ≥ 0.905 и ни один день не ниже base + вето больше чем на 0.005.
- **Частичный успех:** ансамбль `base + st` (вывод последней команды, строка с вето) проходит тот же критерий — тогда в финал идёт ансамбль.
- **Иначе — бросаем.** Разрешена одна повторная попытка: `--pool-frames 1500 --epochs 25` (больше разнообразия, то же время). Больше ничего не перебирать.

### 3. Если успех — финальная модель для test

```bash
python tools/redetect.py pseudo  --tag strong --extra-classes --teacher base --sets all --pool-frames 800 --device 0 --predict-batch 8
python tools/redetect.py train   --tag strong --extra-classes --student --member st --sets all --weights weights/yolo11l.pt --epochs 40 --batch 4 --device 0
python tools/redetect.py predict --tag strong --member st --sets all --device 0
python tools/redetect.py submit  --tag strong --members st          # или --members base st, если прошёл ансамбль
python tools/blend_veto.py test submissions/redetect_strong_st_veto.csv
```

Результат — `submissions/redetect_strong_st_veto_veto.csv`. В Kaggle не отправлять без согласования: отправок мало, выбор финальных двух — командный.
