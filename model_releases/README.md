## Первые временные модели

Два небольших обученных артефакта для совместной работы команды. Внутри — sklearn Pipeline с масштабированием и логистической регрессией, имя варианта и вес смешивания. Исходные изображения, таблицы и индивидуальные предсказания сюда не входят.

| Файл | AP 25 октября | AP 26 октября | Среднее |
|---|---:|---:|---:|
| Baseline (для сравнения) | 0,860737 | 0,764807 | 0,812772 |
| `temporal_core_c1.joblib` | 0,893799 | 0,766122 | 0,829961 |
| `temporal_core_c1_blend.joblib` | 0,892035 | 0,788315 | **0,840175** |

Основной кандидат — `temporal_core_c1_blend`: `score = 0.5 * P(error=1) + 0.5 * (1-confidence)`. Второй файл — чистая регрессия, полезная для сравнения и дальнейших экспериментов.

## Признаки

Регрессия получает пять чисел:

1. Confidence текущего бокса.
2. Максимальный IoU с наиболее похожими боксами того же класса на соседних кадрах.
3. Минимальный из двух лучших IoU — для предыдущего и следующего кадра.
4. Средний confidence пересекающихся соседних боксов минус текущий confidence; 0, если совпадений нет.
5. Максимальный IoU с другим боксом того же класса на текущем кадре; сам бокс исключён.

При отсутствии соседа или кандидата соответствующий IoU равен 0. Берутся предоставленные связи `previous/next`; сосед с другого UTC-дня исключается. Признаки не требуют ручной разметки или машинного пула. Использование следующего кадра соответствует доступному контексту соревнования; для обработки живой камеры без задержки потребовался бы другой вариант модели.

## Проверка и ограничения

Каждый день оценён моделью, обученной на другом дне. Масштабирование также обучено только на обучающем дне. `table` исключён. Файлы моделей после выбора переобучены на всех 198 нестоловых train-боксах; их нельзя заново оценивать на этих же примерах как на отложенных.

Проверено 7 конфигураций и их фиксированные смеси с baseline — всего 14 кандидатов. Результаты всех, включая неудачные, находятся в [отчёте](../reports/temporal_results.md). Лучший вариант выбран на тех же двух днях, поэтому возможна переоценка прироста. Результаты Kaggle приведены в обновлении выше. До этого на этих днях уже сравнивались простые логистические модели.

## Запуск

Из корня репозитория, с локальным датасетом в `data/rascar-hack-case-1/`:

```bash
python -m pip install -r model_releases/requirements.txt
python tools/train_temporal.py --predict model_releases/temporal_core_c1_blend.joblib
```

Результат: `submissions/temporal_core_c1_blend.csv`, 362 строки в порядке шаблона. На Kaggle скрипт ничего не отправляет. Путь к другому датасету задаётся `--data`.

Повторить эксперименты и переобучить оба опубликованных артефакта:

```bash
python tools/train_temporal.py --publish temporal_core_c1_blend temporal_core_c1
python -m unittest discover -s tests -p test_temporal_features.py -v
```

Запуск с `--publish` перезаписывает выбранные локальные артефакты, их метаданные и отчёт, но не выполняет Git push. OOF-ответы сохраняются в игнорируемом каталоге `oof/`. Рядом с каждым артефактом есть JSON с версиями библиотек, метриками и SHA-256 модели и входных обучающих файлов.
